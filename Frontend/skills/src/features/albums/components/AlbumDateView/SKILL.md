---
name: album-date-view
description: "Date-filtered album carousel, previews, and navigation."
---

`src/features/albums/components/AlbumDateView.tsx` renders date selection, the featured album, and the next-album queue. The featured card opens its album and can toggle its favorite state. The compact Next Album button wraps its preview, title, and owner; click, tap, Enter, or Space advances the selected index. Arrow Up and upward swipe or drag also advance. Arrow Down and downward swipe or drag reverse the index. Swipe handling suppresses the button click that follows a drag. When the queue disappears while its button has focus, focus moves to the featured album's open link.

The carousel receives album data, selected date and index, callbacks, loading and error state, and favorite request state. The month button opens the shared `AlbumDateSheet` on web and mobile, using the album feed and daily counts. Done uses the same date callback as the date strip. Dismissing the sheet restores focus to the month button.

The date strip scrolls freely via touch or mouse drag. Mobile changes dates on horizontal swipes starting in the main or subframe. Left advances one day up to today. Right goes back one day. Selecting the active date on mobile resets the album index to zero. Mobile always shows a 64 px album position control in the next-album row. The segmented perimeter ring shows the current position within the selected date and animates as it changes. The current number uses the main color and the total uses muted text. With interface motion enabled, both numbers roll up or down using SlidingNumber when their values change, and the Move up arrow fades in and out. Reduced motion switches both immediately. Activate once to reveal the arrow and again within two seconds to return to the first album. Expiry, selection changes, and unmount clear confirmation. Empty dates show a disabled 0 of 0 counter. The control has a transparent center and a white ring in dark mode. Light mode has a white center and a black ring. Neither theme adds a shadow. The mobile navigation owns the center Add album action. Date and index changes use the page callbacks. Permissions and persistence remain owned by page hooks and album services. `albumCarouselMotion.ts` moves and resizes the traveling 4:3 cover on single-index changes. Mobile uses SwappingText for titles and usernames in both card slots and keeps the queue heading static. The web carousel fades card captions. Different cover contents, including the featured fallback label, crossfade within the moving cover before it lands. The overlay is inert and clears on completion or interruption. Press feedback scales only the compact preview. Motion respects Interface motion and reduced-motion preferences. The compact album title and owner use 75% of their prior font sizes.

`album-date-view.css` owns layout, interaction focus, and compact typography. Missing, failed, and loaded covers have the same 4:3 dimensions in each slot. Both fallbacks show an image icon. The featured fallback adds a localized label. Hover lifts and scales the icons when Interface motion and icon motion are enabled and reduced motion is off. The favorite control uses a quieter surface so the open control remains prominent. Owner labels show usernames without a prefix. Mobile presentation keeps the same 25% reduction from its mobile title and support baselines. `tests/e2e/album-date-view.spec.ts` verifies tap targets, index changes, motion handoff, and responsive typography.

Both layouts show decorative skeletons in both frame slots after the initial album query has been pending for 300 ms. Cached albums remain visible during background refreshes. On mobile, each frame fades in when it gains an album and fades out when it loses one. Loading skeletons fade out independently; an empty slot has no replacement card. Outgoing frames are inert during the fade. Adjacent swaps that keep both slots populated use the existing cover motion. Interface motion off and reduced motion swap frames immediately.

After album metadata arrives, each card shows a cover icon and text skeleton only if its own preview remains pending for 300 ms. The title and owner retain their layout and accessible text during loading. A missing preview or image error reveals the text with the regular no-cover fallback. Available cached images can render immediately. The image and text reveal respects the motion settings.

The featured card hides its contributor row initially without reserving row space. A single preview activation reveals it downward from the preview or collapses it upward, resizing the frame with the row; a double click or double tap toggles the album favorite. The row shows up to five overlapping avatars aligned right, with the owner first and distinct owners of active media after. Hovering or selecting an avatar raises it and reveals its name. Repeat activation, outside press, or Escape clears selection. Motion respects the interface setting and reduced motion.

A failed load without a featured album shows a compact retry panel and hides the queue. Try again calls the page retry callback.

The expanded contributor row shows image and video counts at the left when the album response provides both counts.

The row is clipped during its slide so it emerges from behind the preview. Once expanded, overflow is visible for avatar tooltips.
