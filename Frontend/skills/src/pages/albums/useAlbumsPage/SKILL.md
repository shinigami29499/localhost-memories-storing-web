name: use-albums-page
description: "Filter the loaded album feed by date and create albums."
---

Frontend/src/pages/albums/useAlbumsPage.ts powers the web and mobile gallery lists. The selected date starts at the browser's current local date. The hook groups loaded feed albums by the exact calendar date in albumDate, with the browser-local creation day as the fallback for older albums. It exposes the current index for the two visible slots. Changing the date resets the index. Advancing uses only loaded feed data. The Send Horizontal link opens the main album and records its date, index, and ID in session storage for that Gallery history entry. Returning to the entry restores the opened album as the main preview, preferring the ID when the feed order changes and clamping the index when it does not exist.

The shared AlbumDateView gives the date strip the full gallery width and shows only days in the displayed month through today. It centers the selected date where scroll bounds allow. The first and last dates stop at the gallery gutters at their respective scroll limits. Users browse by mouse drag or touch swipe. Only date activation changes the filter. Dots indicate dates in the loaded feed with albums. The empty state has no create button; the mobile Add album bar opens the New album dialog. Creation sends the selected date as albumDate in YYYY-MM-DD format, invalidates album queries, and records the created album for the list history entry. The returned callback opens the new album. Mobile supplies the date and list history key captured when the dialog opens, then replaces the dialog history entry with album detail.

The fixed carousel reserves space for the Next Album section. Its title and compact album button fade out when there is no next album. Activating the compact preview or its title and owner advances one slot; an upward swipe or drag, or Arrow Up, also advances. A downward gesture or Arrow Down reverses it. The featured preview is passive; the compact preview and text form one keyboard-accessible button. Both previews are flat and use the same 4:3 crop. The animation helper fades the outgoing preview and moves the shared preview between slots. Stable card slots use Animate UI SwappingText for the album title and owner. Gesture handling suppresses button activation on a swipe. Carousel animation respects Interface motion and system reduced motion. Icon motion respects Interface motion, icon motion, and system reduced motion.

The featured card's circular heart toggles persisted album favorite state through `POST` or `DELETE /api/library/album/{id}/favorite`. The spinner stays visible for at least 250ms and until the request and album-list refresh finish, including failures. Only the remaining minimum duration is waited after completion; longer requests add no extra delay. Failures use the shared error toast. Loading ends without zoom; hover pulse respects interface motion, icon motion, and reduced motion.

`tests/e2e/album-favorite.spec.ts` verifies pending, favorite, and unfavorite states.

In dark mode the Gallery page uses `#1c1c1c` and neutral raised surfaces use `#303030`. The main frame and date tiles use exterior shadows. The selected date uses a stronger exterior shadow and paints above neighboring dates. Date borders match their fill at rest and highlight on hover or press. The selected date and Send Horizontal share a near-white fill with near-black content in dark mode. Light mode reverses those colors. Date tiles shrink as they cross the gallery gutters. Animated feedback respects Interface motion and reduced motion.
