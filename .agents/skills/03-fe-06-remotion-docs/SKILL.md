Look up current API references before implementing Remotion features.

1. Search the Remotion docs using the Algolia API described at https://www.remotion.dev/docs/ai/skills.
2. Choose the most relevant documentation URL.
3. Append `.md` to the docs URL to fetch its Markdown source, for example `https://www.remotion.dev/docs/sequence.md`.
4. Implement against current documentation rather than memory.
