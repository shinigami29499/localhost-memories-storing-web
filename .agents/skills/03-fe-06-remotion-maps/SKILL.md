# Remotion Maps

Choose one technique that fits the shot and consult its official technique guide:

- Static map: https://github.com/remotion-dev/skills/tree/main/skills/remotion-maps/techniques/static-map
- Mapbox: https://github.com/remotion-dev/skills/tree/main/skills/remotion-maps/techniques/mapbox
- MapLibre: https://github.com/remotion-dev/skills/tree/main/skills/remotion-maps/techniques/maplibre
- MapTiler: https://github.com/remotion-dev/skills/tree/main/skills/remotion-maps/techniques/maptiler
- CesiumJS: https://github.com/remotion-dev/skills/tree/main/skills/remotion-maps/techniques/cesium

Use these for static maps, animated routes and markers, geographic explainers, GeoJSON, or 3D flyovers. Check provider requirements; some techniques need an API key.
